# MarocTools

Site statique bilingue FR/AR, avec QR Code, redimensionnement d'image, conversion images vers PDF, compteur de mots et générateur de mots de passe.

## Publication GitHub Pages
1. Crée un dépôt public GitHub, par exemple `maroctools`.
2. Décompresse ce ZIP et téléverse les fichiers à la racine du dépôt.
3. Ouvre **Settings → Pages**.
4. Sélectionne **Deploy from a branch**, branche `main`, dossier `/(root)`, puis **Save**.
5. Après déploiement, le site sera à `https://TON-NOM.github.io/maroctools/`.

## Publicité / AdSense
L'espace publicitaire sur la page d'accueil est seulement un emplacement visuel. Après avoir ajouté du contenu original, une page contact réelle et finalisé la politique de confidentialité, suis les instructions officielles AdSense pour connecter le site et insérer le code fourni par Google. L'approbation et les revenus ne sont pas garantis. Ne clique jamais sur tes propres annonces.

## Remarques
Le QR Code et la conversion PDF chargent des bibliothèques depuis un CDN et nécessitent une connexion Internet. La politique de confidentialité est un modèle à compléter.
